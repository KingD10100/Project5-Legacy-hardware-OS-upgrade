# Conclusion: Project Retrospective, Lessons Learned & Strategic Takeaways

## Takeaways & Lessons Learned

1. Upgrading an old mechanical drive instead of tossing the whole laptop keeps perfectly good hardware out of landfills, making component-level upgrades a great way to reduce tech waste.

2. Older processors are rarely the real issue when a computer slows to a crawl. Swapping out a sluggish mechanical drive for an SSD completely removes the performance bottleneck and adds years to the machine’s lifespan.

3. Strict hardware restrictions from OS developers don't mean a machine is obsolete. Using tools like Rufus to bypass native installation blocks lets you keep using perfectly functional legacy hardware without wasting perfectly good computing materials. Just make sure that you harden your system to compensate.
