# Project5-HP-Windows-11-Upgrade-and-Physical-Remediation
Investigated persistent boot and runtime latency. After purging unneeded software and user data to rule out local storage bottlenecks, identified mechanical HDD I/O saturation as the root cause. Executed remediation by upgrading to a high-speed SSD and provisioning a clean Windows 11 image to establish an optimized, patched baseline.
